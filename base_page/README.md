# base_page

[![Powered by Mason](https://img.shields.io/endpoint?url=https%3A%2F%2Ftinyurl.com%2Fmason-badge)](https://github.com/felangel/mason)

Generates a single page for a [vgv_cli](https://github.com/victorsdd01/vgv_cli)
project — `TStateless` or `TStateful`, with or without a bloc wired in.

Use `feature_structure` when you need a whole feature; use this when you are
adding one more page to a feature that already exists.

## What you get

One file, `<base_page_name>_page.dart`:

- **Stateless** (`base_page_type: true`) → `class XPage extends TStateless<B>`
- **Stateful** (`base_page_type: false`) → `XPage extends StatefulWidget` plus
  `_XPageState extends TStateful<XPage, B>`

`B` is your bloc when `include_bloc` is true (resolved with
`Injector.get<B>()`), and `Null` otherwise (then `bloc` returns `null`).
The body is a `Scaffold` with an `AppBar` — replace it with your UI.

## Variables

| Variable | Type | Default | What it is |
|---|---|---|---|
| `project_name` | string | `my_app` | Your package name, used to build the imports |
| `base_page_name` | string | `Example` | Page name; `Profile` → `ProfilePage` in `profile_page.dart` |
| `feature_name` | string | `example` | Feature the page belongs to, used for the bloc import |
| `base_page_type` | boolean | `true` | `true` = Stateless, `false` = Stateful |
| `include_bloc` | boolean | `true` | Wire a bloc into the page |
| `bloc_name` | string | `ExampleBloc` | Bloc class name (only used when `include_bloc`) |

Names are normalized by the brick, so `profile`, `Profile` and `profile_page`
all work.

## Usage

With the vgv CLI, from the folder the page should land in:

```sh
vgv gen brick base_page --url https://github.com/victorsdd01/flutter_bricks \
  -o lib/features/profile/presentation/pages
```

Or with mason directly:

```sh
mason add -g base_page --git-url https://github.com/victorsdd01/flutter_bricks \
  --git-path base_page
mason make base_page -o lib/features/profile/presentation/pages
```

## After generating

- Register the page's route in `application/routes/routes.dart`.
- If you included a bloc, make sure it is registered in
  `application/injector.dart` — `Injector.get<B>()` throws at runtime otherwise.

## Expects

A project generated by vgv_cli, which provides `TStateless` / `TStateful`
(`core/states/`), `Injector` (`application/injector.dart`) and `S`
(`application/generated/l10n.dart`).
