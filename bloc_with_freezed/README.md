# bloc_with_freezed

[![Powered by Mason](https://img.shields.io/endpoint?url=https%3A%2F%2Ftinyurl.com%2Fmason-badge)](https://github.com/felangel/mason)

Generates a `HydratedBloc` with freezed state and events for a
[vgv_cli](https://github.com/victorsdd01/vgv_cli) project — the bloc trio only,
for a feature that already exists.

Use `feature_structure` when you also need the domain and data layers.

## What you get

`<bloc_name>_bloc/` with three files:

| File | Contents |
|---|---|
| `<bloc_name>_bloc.dart` | `XBloc extends HydratedBloc<XEvent, XState>`, takes the feature's `UseCases`, handles `_SomeEvent`, and implements `fromJson`/`toJson` |
| `<bloc_name>_state.dart` | `@freezed abstract class XState` with a `XStatus` enum and a `Failure? failure` excluded from JSON |
| `<bloc_name>_event.dart` | `@freezed sealed class XEvent` with one `someEvent()` variant |

State is persisted: `HydratedBloc` restores it through the generated
`fromJson`/`toJson`.

## Variables

| Variable | Type | Default | What it is |
|---|---|---|---|
| `project_name` | string | `my_app` | Your package name, used to build the imports |
| `feature_name` | string | `example` | Feature that owns the bloc; its `UseCases` is injected |
| `bloc_name` | string | — | Bloc class name, e.g. `Login` → `LoginBloc` |

`bloc_name` does **not** have to match `feature_name` — a feature can hold
several blocs.

## Usage

```sh
vgv gen brick bloc_with_freezed \
  --url https://github.com/victorsdd01/flutter_bricks \
  -o lib/features/orders/presentation/blocs
```

Or with mason directly:

```sh
mason add -g bloc_with_freezed \
  --git-url https://github.com/victorsdd01/flutter_bricks \
  --git-path bloc_with_freezed
mason make bloc_with_freezed -o lib/features/orders/presentation/blocs
```

## After generating

1. Run codegen — the bloc is split across `part` files:
   ```sh
   dart run build_runner build -d
   ```
2. Register it in `application/injector.dart`:
   ```dart
   injector.registerFactory<OrdersBloc>(
     () => OrdersBloc(ordersUseCases: Injector.get<OrdersUseCases>()),
   );
   ```
3. Replace `someEvent` with your real events and handle them with
   `on<_YourEvent>`.

## Expects

A project generated by vgv_cli: a `<feature>UseCases` class under
`features/<feature>/domain/use_cases/`, a `Failure` type in
`core/errors/failures.dart`, and `hydrated_bloc`, `freezed_annotation` and
`dartz` as dependencies.
